# [MERN-stack]

A modern social media platform built for seamless content sharing and interaction. Users can create accounts,
customize their profiles, publish posts and short Reels, and engage with the community through likes and comments in a fast,
responsive interface
--

## Key Features

-  **Auth & Security:** JWT authentication, password hashing (`bcryptjs`), and protected routes.
-  **Full CRUD:** Seamless data management via RESTful APIs.
-  **Responsive UI:** Modern, mobile-friendly design with React & Tailwind CSS.

---

##  Tech Stack

- **Frontend:** React.js, Tailwind CSS, Axios
- **Backend:** Node.js, Express.js, MongoDB (Mongoose)
- **Deployment:** Vercel (Frontend) & Railway/Render (Backend)

---

##  Quick Start

1. **Clone & Install:**
   ```bash
   git clone https://github.com/M-01IQ/MERN-stack.git
   cd MERN-stack

```

2. **Backend Setup (`cd backend`):**
* Install dependencies: `npm install`
* Add `.env` file (`PORT`, `MONGO_URI`, `JWT_SECRET`)
* Run server: `npm run dev`


3. **Frontend Setup (`cd frontend`):**
* Install dependencies: `npm install`
* Add `.env` file (`VITE_API_URL=http://localhost:5000/api`)
* Run app: `npm run dev`
